Story ID: LOGIN-0001 
User Story:
As a registered user,
I want to log in using my registered username and password,
So that I can securely access my account.

Acceptance Criteria:

1. The user should be able to log in using a valid registered username and correct password which is always student and password123

2. The user should see an appropriate error message when an invalid username or password is entered.

3. The username field is mandatory.

4. The password field is mandatory.

6. The password field should mask the entered characters.

7. The user should be redirected to the dashboard after a successful login.

8. The user should remain logged in until they explicitly log out or their session expires.
